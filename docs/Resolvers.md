# Резолверы (шаблоны для подстановки данных в промпты)

## Описание резолверов

Резолверы - это шаблоны, которые подставляют данные в промпты. Они используются для динамического наполнения промптов информацией о проекте и состоянии приложения.

## Доступные резолверы

### {{PROJECT_ROOT}}
Корневая папка проекта

### {{FILE_LIST}}
Список файлов проекта

### {{HISTORY}}
Последние 20 сообщений из чата

### {{OPEN_FILES}}
Содержимое файлов, открытых командой OPEN_FILE

### {{SUPPORTED_COMMANDS}}
Список доступных команд в данном шаге

### {{USER_QUERY}}
Текущий запрос пользователя

### {{LAST_ASSISTANTS_RESPONSE}}
Последний ответ ассистента

### {{FILE_DESCRIPTIONS}}
Описание файлов проекта

### {{PREVIOUS_STEPS}}
Что было уже сделано на предыдущих этапах

### {{TOKEN_COUNT}}
Число токенов текущего контекста

### {{SEARCH_RESULTS}}
Краткие выдержки из SEARCH_WEB / SEARCH_PROJECT

### {{OPEN_SEQUENCE}}
Указать, какую последовательность запустить следующей. Формат: `{{OPEN_SEQUENCE:имя_последовательности,описание}}`

### {{CONTEXT_CHAIN}}
Цепочка контекста из выполненных команд с визуальным статусом
