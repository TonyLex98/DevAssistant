# Команды DevAssistantQt

## Файловые команды

### CREATE_FILE
Создание нового файла
- **Параметры**: `path`, `content`

### REPLACE_IN_FILE  
Замена содержимого файла
- **Параметры**: `path`, `content`

### DELETE_FILE
Удаление файла
- **Параметры**: `path`

### RENAME_FILE
Переименование файла
- **Параметры**: `oldPath`, `newPath`

### EDIT_IN_RANGE
Редактирование части файла в заданных строках
- **Параметры**: `path`, `startLine`, `endLine`, `content`, `replacementLines`

## Команды открытия файлов

### OPEN_FILE (или OPEN_FILE_CONTEXT)
Открытие файла для просмотра
- **Параметры**: `path`

### OPEN_FILE_REGION
Открытие конкретной области файла по номерам строк (нумерация строк начинается с 1, не с 0)
- **Параметры**: `path`, `region`, `startLine`, `endLine`
- **Описание**: Команда открывает указанный файл и возвращает содержимое между startLine и endLine включительно. Нумерация строк начинается с 1. Если указанные номера строк выходят за пределы файла (например, startLine больше общего количества строк в файле, или endLine больше общего количества строк), команда вернёт ошибку. Если используется регулярное выражение (`region`), то оно применяется к содержимому файла. Результат включает пронумерованные строки в формате: "номер_строки| содержимое_строки".
- **Пример использования**: `{"command": "OPEN_FILE_REGION", "params": {"path": "src/main.cpp", "startLine": 10, "endLine": 15}}`
- **Особенности**: Убедитесь, что номера строк действительны - startLine должен быть >= 1, endLine >= startLine, и оба не должны превышать общее количество строк в файле.
- **Для ИИ моделей**: ИСПОЛЬЗУЙ startLine и endLine параметры, чтобы открыть файл с определённой строки по определённую строку! Это КЛЮЧЕВОЕ требование! Пример: `{"command": "OPEN_FILE_REGION", "params": {"path": "имя_файла", "startLine": 5, "endLine": 10}}` - откроет файл "имя_файла" и вытащит строки с 5-й по 10-ю включительно. ПОНИМАЙ, что startLine и endLine - это НОМЕРА СТРОК, а не что-то другое! Это позволяет загрузить только нужную часть файла, а не весь файл целиком.

## Выполнение команд

### RUN_PYTHON
Выполнение Python-скрипта
- **Параметры**: `scriptPath`, `code`

### RUN_SHELL
Выполнение shell-команды
- **Параметры**: `command`

## Поисковые команды

### SEARCH_WEB
Поиск в интернете
- **Параметры**: `query`, `maxResults`

### SEARCH_PROJECT
Поиск по проекту (с опциональной чувствительностью к регистру)
- **Параметры**: `query`, `maxMatches`, `caseSensitive`, `include`

### SEARCH_PROJECT_CASE_INSENSITIVE
Поиск по проекту без учета регистра (новая команда)
- **Параметры**: `query`, `maxMatches`, `include`

## Взаимодействие с пользователем

### ASK_USER
Задать вопрос пользователю
- **Параметры**: `question`

## Работа с описаниями

### WRITE_DESCRIPTION
Написать описание для файла
- **Параметры**: `sourceFilePath`, `description`

## Работа с последовательностями

### CALL_SEQUENCE
Запустить последовательность команд
- **Параметры**: `sequenceName`, `summarize`



## Вспомогательные команды

### SHOW_RESULT
Показать результат
- **Параметры**: `content`, `title`
