## Команды

### ASK_USER
- **Описание**: Запрашивает информацию у пользователя
- **Параметры**: 
  - `question` (string): Вопрос, который будет задан пользователю
  - `defaultAnswer` (string, опционально): Значение по умолчанию
- **Пример**:
```json
{
  "command": "ASK_USER",
  "params": {
    "question": "Какой файл нужно открыть?",
    "defaultAnswer": "main.cpp" 
  }
}
```

### CALL_SEQUENCE
- **Описание**: Вызывает другую последовательность команд
- **Параметры**:
  - `sequenceName` (string): Имя последовательности для вызова
  - `summarize` (bool, опционально): Следует ли добавлять краткое содержание предыдущих действий
- **Пример**:
```json
{
  "command": "CALL_SEQUENCE",
  "params": {
    "sequenceName": "Finder",
    "summarize": true
  }
}
```

### CREATE_FILE
- **Описание**: Создает новый файл с указанным содержимым
- **Параметры**:
  - `path` (string): Путь к создаваемому файлу
  - `content` (string, опционально): Содержимое файла
- **Пример**:
```json
{
  "command": "CREATE_FILE", 
  "params": {
    "path": "C:/project/newfile.cpp",
    "content": "#include <iostream>\nint main() {\n    return 0;\n}"
  }
}
```

### DELETE_FILE
- **Описание**: Удаляет существующий файл
- **Параметры**:
  - `path` (string): Путь к удаляемому файлу
- **Пример**:
```json
{
  "command": "DELETE_FILE",
  "params": {
    "path": "C:/project/oldfile.cpp"
  }
}
```

### EDIT_IN_RANGE
- **Описание**: Заменяет содержимое в указанном диапазоне строк файла
- **Параметры**:
  - `path` (string): Путь к файлу
  - `startLine` (int): Начальная строка (нумерация с 0)
  - `endLine` (int): Конечная строка (не включительно)
  - `newContent` (string): Новое содержимое для замены
- **Пример**:
```json
{
  "command": "EDIT_IN_RANGE",
  "params": {
    "path": "C:/project/main.cpp",
    "startLine": 5,
    "endLine": 8,
    "newContent": "// Updated by AI\n#include <newheader.h>"
  }
}
```

### OPEN_FILE
- **Описание**: Открывает файл и добавляет его содержимое в контекст
- **Параметры**:
  - `path` (string): Путь к файлу для открытия
- **Пример**:
```json
{
  "command": "OPEN_FILE",
  "params": {
    "path": "C:/project/main.cpp"
  }
}
```

### OPEN_FILE_REGION
- **Описание**: Открывает только часть файла (область) и добавляет в контекст
- **Параметры**:
  - `path` (string): Путь к файлу
  - `startLine` (int): Начальная строка (нумерация с 0)
  - `endLine` (int): Конечная строка (не включительно)
- **Пример**:
```json
{
  "command": "OPEN_FILE_REGION", 
  "params": {
    "path": "C:/project/main.cpp",
    "startLine": 10,
    "endLine": 20
  }
}
```

### OPEN_SEQUENCE
- **Описание**: Открывает новую последовательность команд
- **Параметры**:
  - `sequenceName` (string): Имя последовательности для открытия
- **Пример**:
```json
{
  "command": "OPEN_SEQUENCE",
  "params": {
    "sequenceName": "Analyzer"
  }
}
```

### RENAME_FILE
- **Описание**: Переименовывает или перемещает файл
- **Параметры**:
  - `oldPath` (string): Текущий путь к файлу
  - `newPath` (string): Новый путь к файлу
- **Пример**:
```json
{
  "command": "RENAME_FILE",
  "params": {
    "oldPath": "C:/project/oldname.cpp",
    "newPath": "C:/project/newname.cpp"
  }
}
```

### REPLACE_IN_FILE
- **Описание**: Заменяет содержимое всего файла
- **Параметры**:
  - `path` (string): Путь к файлу
  - `content` (string): Новое содержимое файла
- **Пример**:
```json
{
  "command": "REPLACE_IN_FILE",
  "params": {
    "path": "C:/project/main.cpp",
    "content": "#include <iostream>\nint main() {\n    std::cout << \"Hello World\" << std::endl;\n    return 0;\n}"
  }
}
```

### RUN_PYTHON
- **Описание**: Выполняет Python-скрипт и возвращает результат
- **Параметры**:
  - `script` (string): Python-скрипт для выполнения
  - `timeout` (int, опционально): Время ожидания в секундах (по умолчанию 30)
- **Пример**:
```json
{
  "command": "RUN_PYTHON",
  "params": {
    "script": "import os\nprint('Current directory:', os.getcwd())",
    "timeout": 10
  }
}
```

### RUN_SHELL
- **Описание**: Выполняет команду оболочки и возвращает результат
- **Параметры**:
  - `command` (string): Команда оболочки для выполнения
  - `timeout` (int, опционально): Время ожидания в секундах (по умолчанию 30)
- **Пример**:
```json
{
  "command": "RUN_SHELL",
  "params": {
    "command": "dir",
    "timeout": 10
  }
}
```

### SEARCH_PROJECT
- **Описание**: Поиск по файлам проекта
- **Параметры**:
  - `query` (string): Текст для поиска
  - `caseSensitive` (bool, опционально): Учитывать ли регистр (по умолчанию false)
  - `maxMatches` (int, опционально): Максимальное количество совпадений (по умолчанию 10)
- **Пример**:
```json
{
  "command": "SEARCH_PROJECT",
  "params": {
    "query": "function main",
    "caseSensitive": false,
    "maxMatches": 5
  }
}
```

### SEARCH_PROJECT_CASE_INSENSITIVE
- **Описание**: Поиск по файлам проекта без учета регистра
- **Параметры**:
  - `query` (string): Текст для поиска
  - `maxMatches` (int, опционально): Максимальное количество совпадений (по умолчанию 10)
- **Пример**:
```json
{
  "command": "SEARCH_PROJECT_CASE_INSENSITIVE",
  "params": {
    "query": "function main",
    "maxMatches": 5
  }
}
```

### SEARCH_WEB
- **Описание**: Поиск в вебе по заданному запросу
- **Параметры**:
  - `query` (string): Запрос для поиска в интернете
  - `maxResults` (int, опционально): Максимальное количество результатов (по умолчанию 5)
- **Пример**:
```json
{
  "command": "SEARCH_WEB",
  "params": {
    "query": "C++ best practices",
    "maxResults": 3
  }
}
```

### SHOW_RESULT
- **Описание**: Показывает результат пользователю в виде отдельного виджета
- **Параметры**:
  - `content` (string): Содержимое для отображения
  - `title` (string, опционально): Заголовок результата
- **Пример**:
```json
{
  "command": "SHOW_RESULT",
  "params": {
    "title": "Найденные файлы",
    "content": "main.cpp, utils.h, config.json"
  }
}
```

### WRITE_DESCRIPTION
- **Описание**: Записывает описание файла в специальную папку
- **Параметры**:
  - `path` (string): Путь к файлу
  - `description` (string): Описание файла
- **Пример**:
```json
{
  "command": "WRITE_DESCRIPTION",
  "params": {
    "path": "C:/project/main.cpp",
    "description": "Основной файл приложения, содержит точку входа"
  }
}
```

### LIST_FILES_IN_FOLDER
- **Описание**: Получает список файлов в указанной папке
- **Параметры**:
  - `path` (string): Путь к папке
  - `recursive` (bool, опционально): Рекурсивно ли считать подпапки (по умолчанию false)
- **Пример**:
```json
{
  "command": "LIST_FILES_IN_FOLDER",
  "params": {
    "path": "C:/project/src",
    "recursive": true
  }
}
```

## Резолверы

### {{PROJECT_ROOT}}
- **Описание**: Корневая папка проекта
- **Использование**: Вставляет путь к корневой директории текущего проекта

### {{FILE_LIST}}
- **Описание**: Список файлов проекта
- **Использование**: Вставляет полный список файлов проекта

### {{HISTORY}}
- **Описание**: История последних сообщений
- **Использование**: Вставляет последние 20 сообщений из чата (контекст выполнения)

### {{OPEN_FILES}}
- **Описание**: Содержимое открытых файлов
- **Использование**: Вставляет содержимое файлов, открытых командами OPEN_FILE

### {{SUPPORTED_COMMANDS}}
- **Описание**: Список доступных команд
- **Использование**: Вставляет список команд, разрешенных для текущего шага

### {{USER_QUERY}}
- **Описание**: Текущий запрос пользователя
- **Использование**: Вставляет текущий вопрос или запрос пользователя

### {{LAST_ASSISTANTS_RESPONSE}}
- **Описание**: Последний ответ ассистента
- **Использование**: Вставляет последний ответ нейросети

### {{SEARCH_RESULTS}}
- **Описание**: Результаты поисковых команд
- **Использование**: Вставляет результаты команд SEARCH_WEB или SEARCH_PROJECT

### {{CONTEXT_CHAIN}}
- **Описание**: Цепочка контекста из выполненных команд
- **Использование**: Вставляет визуальное представление выполненных команд

### {{FILE_DESCRIPTIONS}}
- **Описание**: Описания файлов проекта
- **Использование**: Вставляет описания файлов из папки DevelopersAssistant

### {{PREVIOUS_STEPS}}
- **Описание**: Краткое содержание выполненных шагов
- **Использование**: Вставляет выжимку из уже выполненных шагов

### {{TOKEN_COUNT}}
- **Описание**: Приблизительная оценка токенов
- **Использование**: Вставляет оценку числа токенов в текущем контексте

### {{OPEN_SEQUENCE_INFO}}
- **Описание**: Список доступных последовательностей в шаблоне
- **Использование**: Вставляет информацию о связанных последовательностях для перехода
- **Формат**: Номер. Описание; sequenceName = "имя_файла_без_.seq.json"; summarize = true/false;

## Форматы использования

### JSON-формат команды
```json
{
  "command": "НАЗВАНИЕ_КОМАНДЫ",
  "params": {
    "параметр1": "значение1",
    "параметр2": "значение2"
  },
  "description": "Описание команды для пользователя"
}
```

### Формат массива команд
```json
[
  {
    "command": "COMMAND1",
    "params": {...},
    "description": "..."
  },
  {
    "command": "COMMAND2", 
    "params": {...},
    "description": "..."
  }
]
```

### Использование резолверов в шаблонах
Резолверы вставляются в шаблоны в формате `{{НАЗВАНИЕ}}`:

```
Контекст проекта:
- Корневая папка: {{PROJECT_ROOT}}
- Список файлов: {{FILE_LIST}}
- Текущий запрос: {{USER_QUERY}}
- История: {{HISTORY}}
```

## Примечания

1. Все команды могут быть объединены в массив для последовательного выполнения
2. Некоторые команды требуют подтверждения от пользователя в зависимости от настроек
3. Пути к файлам должны быть абсолютными или относительно корневой папки проекта
4. Резолверы обрабатываются до выполнения команд и заполняют шаблоны
5. Команды чувствительны к регистру
